# Nihara D Aura — Run & Setup Guide (रन करने की पूरी प्रक्रिया)

इस प्रोजेक्ट में दो मुख्य हिस्से हैं:
1. **Backend (Node.js + Express MVC API)**: Port `5000`
2. **Frontend (React.js + Vite + Tailwind CSS)**: Port `5173`

---

## तरीका 1: अलग-अलग टर्मिनल्स में रन करें (Recommended)

### स्टेप 1: बैकएंड शुरू करें (Terminal 1)
नया टर्मिनल खोलें और यह कमांड्स चलाएं:
```bash
cd "d:\Nihara\Nihara D Aura\backend"
npm run dev
```
👉 इससे बैकएंड सर्वर `http://localhost:5000` पर चालू हो जाएगा।

---

### स्टेप 2: फ्रंटएंड शुरू करें (Terminal 2)
एक दूसरा नया टर्मिनल खोलें और यह कमांड्स चलाएं:
```bash
cd "d:\Nihara\Nihara D Aura\frontend"
npm run dev
```
👉 इससे फ्रंटएंड वेब ऐप `http://localhost:5173` पर चालू हो जाएगा।

---

## तरीका 2: एक ही कमांड से दोनों रन करें (Single Command)

प्रोजेक्ट के मुख्य रूट फोल्डर में जाकर सीधे यह कमांड चलाएं:
```bash
cd "d:\Nihara\Nihara D Aura"
npm run dev
```
👉 यह बैकएंड और फ्रंटएंड दोनों को एक साथ शुरू कर देगा।

---

## ब्राउज़र में ऐप खोलें

जब दोनों सर्वर चालू हो जाएँ, तो अपने ब्राउज़र (Chrome, Edge, आदि) में यह URL खोलें:
🔗 **[http://localhost:5173/](http://localhost:5173/)**

---

## मुख्य फीचर्स जो आप टेस्ट कर सकते हैं:
1. **होम पेज (`/`)**: हीरो बैनर, केटेगरी पिल्स, बेस्टसेलर प्रोडक्ट्स, सिग्नेचर सैलून सर्विसेज।
2. **5-Step ब्यूटी बुकिंग विज़ार्ड (`/book`)**: 
   - सर्विसेज चुनें → डेट और टाइम चुनें → सैलून या होम सर्विस (+₹500) चुनें → आर्टिस्ट चुनें → बुकिंग कन्फर्म करें।
3. **शॉपिंग बैग और डिस्काउंट कूपन (`/cart`)**:
   - प्रोडक्ट्स जोड़ें, कूपन कोड `NIHARA10` (10% OFF) या `GLOW20` (20% OFF) लगाकर टेस्ट करें।
4. **चेकआउट और ऑर्डर प्लेसमेंट (`/checkout`)**:
   - एड्रेस और पेमेंट मेथड चुनकर ऑर्डर कन्फर्म करें।
5. **माई ऑर्डर्स (`/orders`)**:
   - प्लेस्ड ऑर्डर्स की लिस्ट और स्टेटस देखें।
6. **अपॉइंटमेंट्स (`/bookings`)**:
   - शेड्यूल्ड बुकिंग्स देखें और चाहें तो "Cancel Appointment" टेस्ट करें।
7. **प्रोफाइल और एड्रेस मैनेजमेंट (`/profile`, `/addresses`)**:
   - प्रोफाइल और सेव्ड एड्रेसेस एडिट करें।
